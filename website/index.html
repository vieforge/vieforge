3-Tier Hybrid Architecture

Every subtask runs on the lowest-cost tier that satisfies accuracy requirements — keeping Cloud Agents focused on high-leverage thinking.

TIER 1 — CLOUD BRAIN

Architecture & Approval Gates

Cloud Agents (Antigravity, Claude Code, Cursor, Windsurf, Codex) handle design, code edits, reviews, and root-cause debugging — never bulk loops.

TIER 2 — LOCAL BACKBONE ($0)

SQLite WAL + Ollama Leases

Deterministic Python, SHA-256 deduplication, per-item checkpoints, clean-room log trimming (-91%), and ref-counted local LLM VRAM leases.

TIER 3 — ISOLATED MUSCLE

GPU Subprocess & Capped APIs

OS-isolated child processes with exclusive GPU locking for 8 GB+ cards, plus paid APIs guarded by --dry-run, MAX_RETRY <= 2, MAX_JOB_USD, and DAILY_USD_CAP.

Radical Honesty: When VieForge Shines vs. When You Don't Need It

We prefer developer trust over hype. Here is the exact break-even reality.

Massive Savings (10x – 118x)

  • Processing 10 to 5,000+ docs, tickets, emails, CSV rows, or media items in batches.
  • Running noisy test suites, CI builds, or download logs before asking a Cloud Agent to debug.
  • Long multi-stage pipelines where crashes/interrupts normally force expensive full re-runs.
  • Running 2–4 projects simultaneously on one 8 GB+ GPU machine without VRAM OOM crashes.

Minimal Benefit (Skip VieForge Here)

  • Quick 1-turn Q&A or editing a single 50-line file (the 1,459-token session overhead won't pay back in 1 short chat).
  • Purely novel architecture brainstorming that requires a frontier Cloud model for every sentence anyway.
  • Break-even rule: VieForge pays off its 1,459-token overhead after just 1 noisy log or 3–5 batch items.
