System Design

3-Tier Hybrid Architecture

Every subtask runs on the lowest-cost tier that satisfies accuracy requirements — keeping Cloud Agents focused on high-leverage thinking.

TIER 1 · CLOUD BRAIN

Architecture & Approval Gates

Cloud Agents (Antigravity, Claude Code, Cursor, Windsurf, Codex) handle design, code edits, reviews, and root-cause debugging — never bulk loops.

TIER 2 · LOCAL BACKBONE ($0)

SQLite WAL + Local LLM Leases

Deterministic Python, SHA-256 deduplication, per-item checkpoints, clean-room log trimming (-91%), and ref-counted Ollama / OpenAI-compat routing.

TIER 3 · ISOLATED MUSCLE

GPU Subprocess & Capped APIs

OS-isolated child processes with exclusive GPU locking for 8 GB+ cards, plus paid APIs guarded by --dry-run, MAX_RETRY <= 2, MAX_JOB_USD, and DAILY_USD_CAP.

Quick Answers

Frequently Asked Questions

Straight engineering answers before you clone or install.

Do I need an expensive GPU to use VieForge?
No. VieForge runs on CPU-only laptops using qwen2.5:3b (or offline --mock-llm), and automatically adapts to 8 GB, 12–16 GB, 24 GB+ GPUs, and Apple Silicon via preflight_check.py.
Does VieForge send my source code or private data to any server?
Never. SQLite checkpoints, log compression, budget guards, and local LLM routing run 100% on your own machine with zero telemetry, zero analytics cookies, and zero external relay.
How is this different from just running Ollama directly?
Raw Ollama has no per-item SQLite WAL crash/resume, no SHA-256 deduplication, no 91% CI log trimmer, no hard USD budget caps, no ref-counted multi-project VRAM leases, and no MCP server for Cloud Agents. VieForge gives you all of them in 100% Python stdlib.
Can I use VieForge in commercial or agency projects for free?
Yes — forever. The core engine is 100% MIT-licensed Python stdlib, and python -m core.license_audit automatically blocks AGPL-3.0, BUSL-1.1, and CC-BY-NC dependencies.
Which local LLM servers and AI coding agents are supported?
Works with Ollama (native keep_alive=0) plus any OpenAI-compatible server (LM Studio, llama.cpp, vLLM, OpenRouter), and installs skills/MCP configs for Antigravity, Claude Code, Cursor, Windsurf, and Codex CLI.
